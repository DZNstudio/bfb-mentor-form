# Build for Breakpoint mentor form (retired)

A Google Apps Script that builds the mentor intake form for Build for Breakpoint, the founder programme Foundation Ventures ran with Superteam UK ahead of Solana Breakpoint 2026: every question, a linked response sheet and the settings, in one run.

Retired on 15 September 2026 in favour of a Jotform intake. Kept as a reference for the fields a mentor intake needs.

Built by Michael Harding (Foundation Ventures) with Claude Code.
